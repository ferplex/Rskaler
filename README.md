# 🖼️ Rskaler - Escalador 4K para Wallpapers

![Icono](abeja-256.png)

Procesa y escala tus imágenes de Stable Diffusion a resoluciones 4K usando **únicamente tu CPU**. 
🔒 **100% Local y Privado:** Todo el procesamiento ocurre en tu máquina.

## ✨ Características

-  **Resoluciones de Salida:**
  - 4K UHD — 3840×2160 (16:9)
  - 4K Vertical — 2160×3840
  - Ultrawide — 3440×1440
  - 5K — 5120×2880
- 🖼️ **Modos de Wallpaper:**
  - Recortar y llenar (Cover)
  - Ajustar con fondo difuminado (Fit)
- 💾 **Formatos:** PNG (sin pérdida) o JPG (más ligero)
- ️ **Control de Calidad:** Ajustable hasta 92%
- 🧠 **Optimizado para IA:** Funciona mejor con salidas de Stable Diffusion de 512–1024 px

## 📥 Instalación

### Opción 1: Aplicación de Escritorio (Windows)
1. Ve a [Releases](https://github.com/ferplex/Rskaler/releases)
2. Descarga `Rskaler.exe`
3. Ejecútalo directamente

### Opción 2: Versión Web
1. Clona el repositorio: `git clone https://github.com/ferplex/Rskaler.git`
2. Abre `index.html` en tu navegador

## 🛠️ Compilar desde el código fuente

```bash
npm install
npm run build
