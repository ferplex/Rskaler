# 🖼️ Escalador 4K — Wallpapers (CPU)

![License](https://img.shields.io/badge/license-MIT-blue) ![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Web-lightgrey)

Procesa y escala tus imágenes de Stable Diffusion (o cualquier otra) a resoluciones de fondo de pantalla usando **únicamente tu CPU**. 
🔒 **100% Local y Privado:** Todo el procesamiento ocurre en tu máquina. No se sube nada a la nube.

## ✨ Características

- 🚀 **Resoluciones de Salida:**
  - 4K UHD — 3840×2160 (16:9)
  - 4K Vertical — 2160×3840
  - Ultrawide — 3440×1440
  - 5K — 5120×2880
- 🖼️ **Modos de Wallpaper:**
  - Recortar y llenar (Cover)
  - Ajustar con fondo difuminado (Fit)
- 💾 **Formatos:** PNG (sin pérdida) o JPG (más ligero).
- ⚙️ **Control de Calidad:** Ajustable hasta 92%.
- 🧠 **Optimizado para IA:** Funciona mejor con salidas de Stable Diffusion de 512–1024 px.

## 📥 Instalación y Uso

### Opción 1: Aplicación de Escritorio (Windows)
1. Ve a la sección de [Releases](https://github.com/ferplex/rsakaler/releases) de este repositorio.
2. Descarga el archivo `Escalador4K.exe`.
3. Ejecútalo. ¡No requiere instalación!

### Opción 2: Versión Web (Local)
1. Clona este repositorio: `git clone https://github.com/TU_USUARIO/TU_REPO.git`
2. Abre el archivo `index.html` en tu navegador favorito (Chrome/Edge recomendados).

## ⚠️ Nota sobre el Rendimiento
El enfoque está diseñado para trabajar con la CPU. Escalar a 4K puede tardar unos segundos (o un poco más en equipos antiguos); es el precio de mantener tu privacidad y no depender de servidores externos. 😉

## 🛠️ Tecnologías
- HTML5 / CSS3 / JavaScript
- Procesamiento de imagen en el navegador (Canvas API / WASM)
- Empaquetado con Electron (para la versión `.exe`)
